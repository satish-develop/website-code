# Cloud Data Tech LLC Website

Responsive company website for Cloud Data Tech LLC, an IT consulting and development firm.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Notes

- Primary app code: `src/App.jsx`
- Site styles: `src/App.css`
- Generated hero image: `public/assets/cloud-data-hero.png`
- Contact form opens a prepared email to `contact@clouddatatechllc.com`
